# PRD - 个人网站项目

## 项目目标
搭建一个属于刘一诺的个人简历/作品展示网站，可通过 GitHub Pages 公开访问。

## 用户场景
- 目标受众：同学、授课教师、未来实习/研究生申请时的审核者
- 访问场景：通过浏览器访问 yaamaaguuchii.github.io
- 用户需求：快速了解刘一诺的专业背景、技术能力、项目经历和联系方式

## 本期范围（做）
- Hero 区域：姓名、专业、一句话定位
- About 区域：个人简介
- Skills 区域：技术栈和工具列表
- Projects 区域：课程作业和项目展示
- Contact 区域：邮箱联系方式
- GitHub Pages 部署
- 响应式设计（桌面端和移动端均可读）

## 本期不做（不做）
- 不接入数据库、登录/注册、支付功能
- 不添加后端服务
- 不暴露个人隐私（身份证号、家庭住址、手机号、密码、API Key 等）

## 成功标准
1. 网站可通过 https://yaamaaguuchii.github.io 访问
2. 所有占位内容已替换为真实个人信息
3. 项目链接和联系方式有效可点击
4. 桌面端和移动端均可正常浏览
5. README 中记录 GitHub Pages 正式链接
6. docs/ 目录包含 PRD、Design、Checklist 三份文档
