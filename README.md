# 刘一诺 - 个人网站

这是我的个人简历/作品展示网站，基于 Modern Resume Theme 模板搭建，部署在 GitHub Pages 上。

## 模板来源
- 原始模板：[sproogen/modern-resume-theme](https://github.com/sproogen/modern-resume-theme)

## 主要修改内容
- 替换为真实个人信息（姓名、专业、简介）
- 更新项目展示和教育经历
- 配置 GitHub Pages 部署
